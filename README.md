# sis-therapist (Deprecated)

`sis-therapist` was an early static website built using **HTML, CSS, and JavaScript**, and then with **Next.js, React and TypeScript**, as a trial run, to explore the initial concept of a therapist-focused web presence.

As the project evolved, requirements around accessibility, design quality, scalability, and maintainability outgrew what a static implementation could reasonably support.

The project has since been **reimplemented from scratch** using a modern tech stack under the new name **Mindsake**.
